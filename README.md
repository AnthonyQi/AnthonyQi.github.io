# Anthony Qi — Portfolio

Personal portfolio website built to showcase my software engineering, game development, interactive media, and future art/design work.

**Live Site:** [https://anthonyqi.github.io](https://anthonyqi.github.io)

---

## Overview

This portfolio is designed around a lightweight terminal / desktop-inspired aesthetic.

Rather than building a conventional portfolio consisting only of static project cards, I wanted the site itself to have some personality and interactivity while still remaining fast and usable.

The current site includes:

- Hero / introduction
- Featured software projects
- Game development projects
- Interactive skills section
- Experience timeline
- Resume download
- Contact and social links
- Dark / light mode
- Terminal-style section animations
- A playable Pachinko game embedded directly into the portfolio

The site is built with React, TypeScript, Tailwind CSS, and Vite and is deployed through GitHub Pages.

---

## Design

The visual design combines:

- terminal commands
- monospace typography
- desktop-style windows
- minimal grayscale UI
- subtle animations
- interactive components
- light and dark themes

Sections appear as terminal-style windows with commands such as:

```text
ls ./featured_projects
ls ./game_projects
ls ./skills
ls ./experience
cat ./contact.json
download ./resume.pdf
```


My future goal with this website is to maintain essentially an archive of all projects I have worked on with or without other group memebers.
